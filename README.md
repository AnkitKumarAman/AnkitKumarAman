## ⚡ Featured Project

### [SpaceInvader Retro Arcade Game 🚀👾](https://github.com/AnkitKumarAman/SpaceInvader)
A high-performance 8-bit retro arcade game built with **Python**, **Pygame-CE**, and **SDL**.

* **🔊 DSP Audio Synthesis Engine**: Programmed a procedural DSP math engine using Python's native `wave` and `struct` libraries to synthesize frequency-swept square wave lasers, triangle wave bass, and decaying white-noise explosions in memory.
* **⚙️ Stateful Systems**: Engineered single/rapid weapon firing rate limiting, a real-time HUD heat/overheat tracking bar, and dynamic item drops (Shield, Triple-Shot, weapon cooling resets).
* **🌀 Kinematics & Mechanics**: Built 2D vector kinematics (`pygame.Vector2`) for drift physics, multi-particle explosion debris scattering, screen-shake offsets, and a 3-layer parallax scrolling starfield.
* **💾 Data Serialization**: Implemented high score persistent tracking using local filesystem I/O caching.
